# Single-position hardware recordings

User-provided recordings associated with the `single-position-v0.3.0` hardware
edition. The original video and audio streams are preserved; no transcoding or
editing was performed. Videos are attached to the release rather than stored
in Git source history.

| Recording | Download original | Duration | Video format |
|---|---|---|---|
| Motive motion-capture view | [Motive View.mp4](https://github.com/khubaib007/Safe-Redcho-Crazyflies/releases/download/single-position-v0.3.0/Motive-View.mp4) | 107.87 s | H.264 MP4, 1896 × 1028 |
| Physical flight camera view | [Live stream.MOV](https://github.com/khubaib007/Safe-Redcho-Crazyflies/releases/download/single-position-v0.3.0/Live-stream.MOV) | 100.50 s | HEVC MOV, encoded 1920 × 1080 |

The supplied live file is named **`Live stream.MOV`**; no file named
`Live stream.mp4` was present. Release asset names use hyphens for stable download
links. File contents are identical to the supplied originals.

[File sizes, codec information and SHA256 hashes](media/flight_videos.metadata.json)
are included for integrity checking. Download the MOV for playback in a player
that supports HEVC if your browser does not support that format.

These are separate recordings. Their timestamps have not been aligned or
synchronized here, and no complete mission/landing outcome is inferred from
these media files. The earlier [flight-data replay](REAL_FLIGHT_REPLAY.md)
remains available separately with its own displayed interval and annotations.
